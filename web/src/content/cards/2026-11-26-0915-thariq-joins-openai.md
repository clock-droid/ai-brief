코딩 에이전트 Claude Code 이야기로 개발자들 사이에 이름이 알려진 타리크 시히파르(Thariq Shihipar)가 11월 25일 앤트로픽을 떠나 OpenAI에 합류했다고 X에 밝혔어요. 그는 앤트로픽에서 보낸 시간이 자랑스럽고 옛 동료들을 계속 응원하겠다며 "두 회사 모두 앞으로 맡을 중요한 역할이 있다"고 썼어요.

Latent Space는 같은 날 뉴스레터에서 이번 이동을 최근 캣 우(Cat Wu)에 이은 두 번째 '앤트로픽→OpenAI' 유명 인사 이적으로 꼽았어요. 시히파르는 이적 발표 전 AI Engineer CODE 무대에서, 에이전트가 기능을 통째로 만들어 주면 정작 만드는 사람이 자기 소프트웨어를 이해하지 못하게 된다며 사람이 직접 읽고 고치는 층을 따로 두자고 제안했는데요. 그 강연 내용은 원문 요약 글에 정리했어요.

다만 OpenAI에서 무슨 일을 맡는지는 아직 밝혀지지 않았어요.
