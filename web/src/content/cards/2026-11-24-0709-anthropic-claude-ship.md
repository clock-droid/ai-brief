- 앤트로픽(Anthropic)이 클로드가 GitHub 풀 리퀘스트(PR, 코드 변경 제안)를 팀 정책에 따라 검토하고 고치고 승인할 수 있게 하는 Claude Ship을 공개했다고 Techmeme가 전함.
- Claude Team과 Enterprise 요금제에서 베타로 제공됨.
- 트윗을 쓴 사용자는 내부에서 쓰고 있다며 추천했으나, 소속은 확인하지 못함.
- 다만 앤트로픽 공식 발표문은 확인하지 못했고 Techmeme 헤드라인 기준임. 승인 범위나 가격 등 세부는 알 수 없음.

한 줄 요약: 클로드가 PR의 검토·수정·승인까지 맡는 기능이 팀·기업용 베타로 나옴.

※ 기존 Code Review 기능은 승인·차단을 하지 않는다고 공식 문서에 나와 있어, 이번 기능과 범위가 다를 수 있음.
