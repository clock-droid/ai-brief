마이크로소프트 AI(MAI)가 11월 23일, 자체 강화학습(RL) 틀 '로켓(Rocket)'의 기술 보고서를 공개했어요. 핵심 주장은 다른 회사 모델을 베끼는 '증류' 없이, 3조 파라미터 기반 모델 'MAI 베이스 2(MAI Base 2)'를 강화학습만으로 끌어올리는 중이고 그 모델이 자사 종합 벤치마크에서 클로드 오퍼스 4.8을 넘어섰다는 거예요.

**증류 없이 강화학습으로 오른다는 게 뭐야?**

증류(distillation)는 더 센 '선생' 모델의 답을 보고 배우게 하는 방법이에요. 보고서는 증류한 모델은 강화학습을 시작할 때 이미 천장 근처에 있어서 강화학습이 짧은 마무리 단계가 된다고 설명하는데요. MAI는 반대로 기반 모델에서 출발해 강화학습 자체로 수천 단계, 몇 주~몇 달 동안 GPU 수천 개를 돌리는 길을 택했어요. 다른 연구소 모델에 기대지 않는 게 "자립의 핵심"이라는 것.

**오래 돌리면 뭐가 문제야?**

작은 어긋남이 쌓여요. 소프트웨어 개발 과제 하나는 중앙값 93분, 249번의 모델 호출이 걸리는데 그 사이에도 학습은 계속되니, 답을 만든 모델과 배우는 모델이 점점 달라져요(보고서는 이걸 '낡음(staleness)'이라 불러요). 로켓은 15초 만에 가중치를 추론 서버로 보내 자주 갱신하고, 시작한 작업을 새 작업보다 먼저 처리하고, 실패한 작업은 다시 돌리지 않고 버리는 식으로 이 차이를 줄였다고 해요. 답을 만드는 쪽과 배우는 쪽의 계산 결과를 비트 단위까지 똑같이 맞췄더니, 작은 모델 실험에서 같은 단계 기준 점수가 더 높게 올랐다고. 고장 난 부분만 따로 살리는 복구 기능으로는 GPU 6,000개 기준 전체 GPU 시간의 17.37%를 아꼈다고 추산했어요.

**어디까지 믿어도 돼?**

비교 점수는 수십 개 공개·비공개 평가를 합친 MAI 자체 종합 벤치마크예요. 그림에 표시된 기준선은 오퍼스 4.8 66.0%, GPT-5.6 솔 73.3%이고, MAI는 "몇 주 안에" 솔도 넘을 거라고 했어요. 두 비교 대상 모두 경쟁사의 이전 세대 모델이고, 모델 자체는 아직 공개되지 않았어요.
