- 퍼플렉시티(Perplexity)가 정해진 주기로 웹을 검색해 의미 있는 변화가 있을 때만 웹훅으로 에이전트에 알려주는 모니터 API(Monitor API)를 내놓음.
- 개발자가 자연어로 감시 대상을 적으면 자체 판단 모델이 관련성·출처 신뢰도·새로움·시의성을 거르고 신뢰도 점수와 함께 알림을 보냄.
- 웹 모니터는 검색어 기준, 페이지 모니터는 최대 10개 페이지의 기준본을 저장해 변경분을 텍스트로 알려줌. 실행 주기는 15분 단위부터 주 단위, 크론 지정까지 가능함.
- 가격은 웹 모니터 1000회 성공 실행당 1달러, 페이지 모니터 1000개 URL당 1달러임.
- 다만 60개 주제 테스트에서 8시간 동안 새 관련 페이지 63개를 찾아 파이어크롤(20개)·엑사(15개)를 앞섰다는 수치는 회사 내부의 초기 결과임.

한 줄 요약: 퍼플렉시티가 에이전트용 웹 변경 감시 API를 출시했고, 성능 비교는 회사 자체 초기 테스트 결과임.
