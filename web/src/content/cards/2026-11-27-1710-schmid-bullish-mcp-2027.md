한물갔다는 말을 듣던 MCP가 오히려 내년 에이전트의 중심이 될 거라는 주장이 나왔어요. 구글 딥마인드(Google DeepMind)의 개발자 관계 엔지니어 필립 슈미트(Philipp Schmid)가 11월 26일 블로그와 X에 올린 글에서 "가장 좋은 하네스는 가장 좋은 MCP 클라이언트를 가진 쪽"이 될 거라고 했어요.

**MCP가 뭐야?**

MCP(Model Context Protocol)는 AI 모델이 외부 도구·데이터에 붙는 방식을 하나로 맞춘 공개 규격이에요. 앤트로픽이 2024년 11월 내놨는데요. 연결한 서버의 도구 설명이 전부 프롬프트에 들어가 맥락을 잡아먹는다는 불만이 컸고, 앤트로픽 '스킬(Skills)'이 나온 뒤엔 많은 개발자가 명령줄 도구(CLI)로 옮겨 갔어요. 슈미트는 이 흐름이 바뀌고 있다며 숫자를 댔어요. 아틀라시안(Atlassian)에선 MCP가 평일 하루 500만 건 넘는 도구 호출을 처리하고 그 사용자 44%가 비개발 부서이고, 노션(Notion)은 MCP 트래픽이 60배 늘었다고.

**무엇이 달라졌다는 거야?**

그가 꼽은 건 네 가지예요. 도구를 하나씩 부르는 대신 모델이 짧은 코드로 여러 도구를 엮어 부르고 결과만 받는 '코드 모드', 서버가 사용법(스킬)을 직접 내려주고 바뀌면 자동으로 새 판을 받는 스킬 확장, 새벽 보안 경보 같은 외부 사건이 에이전트를 깨우는 이벤트 확장, 채팅 안에 그래프·대시보드 화면을 띄우는 MCP 앱이에요. 다만 서버가 사용자의 의도를 모른다는 점, 서버를 찾는 방법, 프롬프트 주입 공격의 통로가 넓어지는 보안 문제는 아직 남았다고 슈미트 스스로 짚었어요. 기업별 사용량은 그가 각 회사 발표를 모은 것이에요.
