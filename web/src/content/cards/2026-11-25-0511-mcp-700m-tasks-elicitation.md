- 앤트로픽(Anthropic)이 공개 2년 된 MCP(모델 컨텍스트 프로토콜, AI가 외부 도구·데이터에 붙는 표준)의 개발 도구(SDK) 다운로드가 월 7억 회를 넘고, Claude용 MCP 커넥터가 1만 개를 넘었다고 밝힘.
- 10월 공개 시험을 거친 '태스크(Tasks)'와 '일리시테이션(Elicitation)'이 정식 출시됨. 태스크는 서버가 긴 작업을 뒤에서 돌리고 끝나면 결과를 알리는 기능, 일리시테이션은 작업 중 멈춰 사용자에게 빠진 정보를 묻는 기능임.
- 서버가 도구와 함께 사용자·조직 맞춤 지침을 주는 'Skills over MCP'는 베타로 나옴.
- PDF·표·이미지를 MCP 서버로 바로 넘기는 파일 업로드도 곧 Pro·Max·Ultra와 Team·Enterprise에 나온다고 함.
- 도구 설명을 필요할 때만 불러오는 방식으로 여러 서버를 쓸 때 맥락 사용량을 85% 넘게 줄일 수 있다고 앤트로픽은 밝힘.

한 줄 요약: MCP가 단순 연결 규격에서 에이전트가 오래, 스스로 일하게 하는 규격으로 넓어짐.
