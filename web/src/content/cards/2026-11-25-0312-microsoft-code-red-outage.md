- 로이터는 내부 메모를 근거로 마이크로소프트(Microsoft)가 대형 서비스 장애를 막고 대응하는 방식을 뜯어고치는 '코드 레드(Code Red)' 작업을 선포했다고 11월 24일 보도함.
- 계기는 24시간 동안 이어진 마이크로소프트 365 장애였다고 함.
- 다만 원문(로이터)은 확인하지 못했고 Techmeme 헤드라인 기준임.

한 줄 요약: 하루 동안의 장애를 겪은 MS가 장애 예방·대응 방식을 다시 짜기로 함.
