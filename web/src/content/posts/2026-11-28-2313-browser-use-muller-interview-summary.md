독일 유튜브 채널 에버라스트 AI(Everlast AI)가 11월 26일 공개한 약 67분짜리 인터뷰예요. 출연자는 AI 에이전트가 웹 브라우저를 직접 쓰게 해 주는 오픈소스 도구 브라우저 유즈(Browser Use)의 공동창업자 겸 CEO 마그누스 뮐러(Magnus Müller). 진행자는 그를 세계에서 가장 빠르게 크는 오픈소스 프로젝트 중 하나를 만든 사람으로 소개했어요. 아래는 영상 자막(영어 번역 자막) 기준으로 그의 말을 흐름 순서대로 줄인 것이고, 모델 이름과 수치는 모두 뮐러의 주장이에요.

**올해 무엇이 달라졌나**

뮐러는 올해 브라우저 에이전트의 신뢰성이 크게 올랐다고 봤어요. 작년엔 모델이 어떻게 움직여야 하는지 단계마다 적은 거대한 프롬프트가 필요했는데, 올해 초 클로드 오퍼스 4.5·4.6 무렵부터 믿고 맡길 만해졌고, 이제는 사람들이 신용카드와 개인 데이터를 넘기고 작업을 통째로 맡긴다는 것. 그가 말하는 브라우저 유즈의 쓸모는 '자동화의 마지막 1마일'이에요. 비행기 표를 사고, 기차 앱에 가입하고, 페이팔 오류를 고치고, 왓츠앱으로 알리는 식의 자잘한 단계는 하나하나 스크립트로 짜기 어려운데, 지능이 있는 에이전트는 처음 보는 사이트도 알아서 다룰 수 있다는 것이에요.

예전 브라우저 자동화 도구인 셀레늄(Selenium)·플레이라이트(Playwright)와의 차이도 같은 데서 찾았어요. 예전엔 사람이 스크립트를 짜야 했고 사이트 화면이 바뀌면 고쳐야 했는데, 이제는 모델이 사이트 변화에 맞춰 스스로 적응한다는 것. 브라우저 유즈도 내부에서 플레이라이트를 쓰지만, 핵심은 "에이전트에게 브라우저 유즈를 쓰라고 말하면 그냥 된다"는 쉬움이라고 했어요. 그가 놀랐다고 꼽은 사례는 기업 간 사기 탐지예요. 결제 회사가 새 가입 업체가 진짜 회사인지 확인하려면 웹사이트를 돌며 링크와 SNS를 눌러 봐야 하는데, 이건 API 하나로 해결할 수 없어 "자동화 루프 안에 지능"이 필요하다는 것.

**벤치마크와 모델 선택**

OSWorld 같은 공개 벤치마크는 별로 쓰지 않는다고 했어요. 연구자가 상상해 만든 과제라 실제 쓰임과 다르고, 모델이 금방 높은 점수를 받아 포화되기 때문이에요. 그래서 실제 사용자 과제로 모델 정확도가 50% 안팎에 그치는 더 어려운 벤치마크를 직접 만들고, 이것이 앤트로픽·딥마인드 같은 연구소와 일하는 통로가 된다고 했어요. 자기 모델이 못하다고 나오면 연구소가 바로 연락해 온다는 것.

모델을 고르는 방식도 작업 종류에 따라 갈린다고 했어요. 한 번만 하는 작업(비행기 예약)엔 가장 좋은 모델을 쓰고, 같은 일을 계속 돌리는 작업(사기 탐지)엔 프롬프트를 공들여 쓰고 싼 모델을 쓴다는 것. 그의 클라우드에서 지금 가장 많이 쓰이는 모델은 OpenAI의 작은 모델 Luna(높은 추론 설정)이고, 매우 복잡한 일회성 작업엔 큰 모델 Astra가 쓰인다고 했어요. 가로축 비용, 세로축 정확도로 그린 그래프에서 그동안 Luna가 가장 싸고 좋은 쪽을 차지했는데, 딥시크(DeepSeek) 4.1 Flash가 처음으로 이 비용 대비 정확도에서 Luna를 앞섰다고 주장했어요. 공개 모델 중에선 샤오미(Xiaomi) 새 모델과 큐원(Qwen) 3.8도 좋게 봤어요.

**프런티어 모델이 아직 못하는 것**

뮐러는 남은 개선 여지를 속도와 효율에서 찾았어요. OpenAI를 위해 같은 과제를 8번 돌려 보면 1번은 실패하고 3번은 성공하고 나머지는 중간 수준의 문제가 생기는데, 성공한 경우끼리도 5분 걸릴 때와 1시간 걸릴 때가 있다는 것. 링크 100개를 처리할 때 먼저 다 모아 동시에 돌리느냐, 하나씩 차례로 하느냐 같은 작은 전략 차이가 시간을 가른다고 했어요. 초당 1,000토큰을 내는 빠른 모델이 있어도 단계마다 더 똑똑하게 움직이는 모델이 오히려 먼저 끝난다며, 사후 학습(post-training)으로 좋은 전략을 가르치는 게 지렛대라고 봤어요. 도구 쪽에서도 같은 사이트를 두 번째 찾을 때 빨라지도록, 처음 탐색하며 배운 것을 마크다운 '스킬 파일'로 저장한다고 했어요.

미국 모델이 에이전트 작업에서 앞선 이유는 강화학습 '환경'(과제와 성공 여부를 알려 주는 연습장)에 훨씬 많은 돈을 써 왔기 때문이라고 봤어요. 다만 환경을 만드는 회사들이 미국 연구소에 판 뒤 중국 회사에도 팔기 시작해 격차가 줄고 있다고 했어요.

**브라우저가 사라진다**

1년 반 전 OpenAI가 AI 브라우저 아틀라스(Atlas)를 냈을 때 브라우저 유즈가 끝났다는 말이 나왔지만, 오히려 무료 오픈소스 대안을 찾는 사람이 몰렸다고 했어요. 그리고 지금 결론은 사람들에게 새 브라우저가 필요한 게 아니라 브라우저 자체가 필요 없어진다는 것. "우리 팀은 이제 크롬을 안 써요"라며, 모든 걸 에이전트로 한다고 했어요. 결제는 스트라이프(Stripe) 연동으로 에이전트가 카드 번호를 직접 보지 않고 일회용 번호를 만들어 쓰게 했는데, 에이전트용 암호화폐 결제(x402)도 지원하지만 들어오는 돈은 거의 없다고 했어요. 사람들은 그냥 신용카드를 쓴다는 것.

**다음 병목은 사람**

그가 꼽은 다음 과제는 셋이에요. 첫째, 의도를 말한 뒤 결과가 나오기까지의 속도. 둘째, 모델이 매번 처음부터 시작하지 않고 사용자의 관심과 가치를 배우는 '지속 학습(continual learning)'으로, 내년에 크게 풀릴 거라고 봤어요. 셋째는 사람의 창의성이에요. "컴퓨터에 뭐든 시킬 수 있게 됐는데, 무엇을 시킬지가 점점 병목"이라는 것. 그래서 그는 AI가 먼저 할 일을 제안하고 사람은 예·아니오만 고르는, 데이트 앱처럼 넘기는 내부 도구를 만들어 쓰고 있다고 했어요.

샌프란시스코 연구소 사람들과 자주 만나지만 그들이 2년 앞선 비밀을 쥐고 있진 않고, 차이는 짓고 있는 데이터센터와 컴퓨트 규모라고 했어요. 회사는 4~5명 규모로 소개됐어요.

다만 이 인터뷰는 자사 제품을 알리는 자리이기도 해서, 신뢰성이 올랐다는 평가와 모델 비교는 브라우저 유즈 자체 측정과 고객 사용 기준이에요. 외부 검증 수치는 영상에 나오지 않아요.
